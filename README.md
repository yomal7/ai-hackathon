# Rakshaka

An AI agent network that stops phone scammers from emptying elders' bank accounts.
Built in Jac / Jaseci for the Jaseci Labs AI Hackathon.

**Simulation - fictional data.** All banks, people, accounts and money are fictional.

## Run

```bash
pip install jaseci
jac install
cp .env.example .env   # add your keys
jac start --dev main.jac
```

Tests: `jac test`
